# 🎋 Bambus Client – Anleitung

Du brauchst nur **Minecraft Java Edition** (gekauft). Java ist im Launcher schon eingebaut.

---

## Mac

1. **`Bambus-Launcher-Mac-AppleSilicon.dmg`** öffnen (für Macs mit M1/M2/M3/M4-Chip).
   Ältere Macs mit Intel-Chip: `Bambus-Launcher-Mac-Intel.dmg`.
   *Welcher Chip? Apfel-Menü  → „Über diesen Mac“ → bei „Chip“ steht z. B. „Apple M2“.*
2. **Bambus Launcher** in den Ordner **Programme** ziehen.
3. Beim ersten Öffnen sagt der Mac wahrscheinlich, die App sei von einem „nicht verifizierten Entwickler“:
   - **Systemeinstellungen → Datenschutz & Sicherheit** → ganz unten **„Dennoch öffnen“** klicken.
   - Falls „ist beschädigt“ erscheint: Programm **Terminal** öffnen und eingeben:
     `xattr -cr "/Applications/Bambus Launcher.app"` → Enter → noch mal öffnen.
   *(Das liegt nur daran, dass der Bambus Launcher keine gekaufte Apple-Signatur hat.)*
4. **Im Dock behalten:** Wenn der Launcher läuft, Rechtsklick auf das Bambus-Symbol im Dock →
   **Optionen → Im Dock behalten**.

## Windows

1. **`Bambus-Launcher-Setup.exe`** doppelklicken. Falls „Der Computer wurde durch Windows geschützt“ erscheint:
   *Weitere Informationen* → *Trotzdem ausführen*.
2. Das Setup legt den Launcher ins Startmenü und auf den Desktop und startet ihn.
3. **In die Taskleiste:** Rechtsklick auf das Bambus-Symbol unten in der Taskleiste → **„An Taskleiste anheften“**.

---

## Spielen

1. Im Bambus Launcher auf **SPIELEN** klicken. Beim ersten Mal wird alles eingerichtet (Internet nötig).
2. Der Minecraft Launcher öffnet sich. Dort das Profil **„Bambus Client“** auswählen → **Spielen**.
3. Im Spiel: **Rechts-Shift** öffnet das Bambus-Menü. Mit **Tab** wechselst du die Tabs.

| Taste | Was passiert |
|---|---|
| Rechts-Shift | Bambus-Menü |
| C (halten) + Mausrad | Zoom |
| Linke Alt / Option (halten) | Freelook |
| H | HUD an/aus |
| (frei wählbar) | Koordinaten kopieren – unter Tastenbelegung festlegen |

*Mac-Tipp: Viele Mac-Tastaturen haben keine rechte Shift-Taste mit Abstand – die Tasten kannst du im Spiel unter
Optionen → Steuerung → Tastenbelegung → „Bambus Client“ ändern.*

## ✅ Testliste – funktioniert alles?

Hake ab, was klappt. Wenn etwas nicht klappt, schreib dazu, was passiert (oder mach ein Bildschirmfoto).

**Launcher**
- [ ] Launcher startet, Neon-Fenster erscheint
- [ ] Beim ersten Start erscheint die Willkommens-Seite (Sprache, Name, Look, Leistung)
- [ ] Seite HELFER: „Rezept Zaubertisch“ fragen – das Rezept erscheint als Bild
- [ ] Einstellungen → ENGLISH: der Launcher ist auf Englisch
- [ ] Tabs links (Start, Module, Kosmetik, Mods, Server, Neuigkeiten, Einstellungen) lassen sich anklicken
- [ ] Hintergrund bewegt sich; Einstellungen → HINTERGRUND wechselt ihn
- [ ] Server: Lieblingsserver zeigen Spieler und Ping; neuen Server hinzufügen klappt
- [ ] Module: Schalter gehen an und aus
- [ ] Kosmetik: dein eigener Skin wird angezeigt (sonst: Namen eingeben → LADEN)
- [ ] Kosmetik: Figur lässt sich mit der Maus drehen, VORNE/HINTEN funktionieren
- [ ] Kosmetik: Cape, Flügel und Partikel wechseln in der Vorschau
- [ ] SPIELEN: Fortschrittsbalken läuft bis 100 %, Minecraft Launcher öffnet sich
- [ ] Im Minecraft Launcher gibt es das Profil „Bambus Client“ mit Bambus-Symbol

**Im Spiel**
- [ ] Minecraft startet, Fenstertitel „Bambus Client“, Bambus-Logo im Hauptmenü
- [ ] HUD oben links (FPS, Koordinaten, CPS) und Keystrokes sind zu sehen
- [ ] Rechts-Shift öffnet das Neon-Menü, Tab wechselt die Tabs
- [ ] Module an/aus funktionieren, HUD BEARBEITEN: Anzeigen lassen sich verschieben und rasten ein
- [ ] HUD BEARBEITEN: Größe ändert sich mit der Ecke oder dem Mausrad, Rechtsklick = 100 %
- [ ] Neue Module: Kompass-Balken, Koordinaten (mit Nether-Umrechnung), Spielzeit, Ping-Verlauf
- [ ] Beim Betreten einer Welt erscheint der Bambus-Ladebildschirm
- [ ] Benachrichtigungen unten rechts (z. B. H drücken → „Bambus-HUD ausgeschaltet“)
- [ ] Mehrspieler: die Server aus dem Launcher stehen in der Liste
- [ ] Zoom (C) und Mausrad-Zoom
- [ ] Freelook (Alt halten): umschauen, ohne die Laufrichtung zu ändern
- [ ] Fadenkreuz: Form, Farbe, Größe ändern sich
- [ ] Kosmetik im Spiel: Umhang sichtbar (F5 drücken für 3. Person) und weht – im Stand leicht, beim Sprinten stark
- [ ] Umhang-Animation läuft (z. B. Matrix: Datenregen, Glut: Flammen)
- [ ] Flügel sichtbar, schlagen beim Laufen, gleiten im Stand, legen sich beim Schleichen an (F5)
- [ ] Flügel: keine Lücken beim Schlagen, Knochen an der Vorderkante, Ansatz sitzt am Rücken
- [ ] Flügel + Umhang zusammen: Flügel sitzen über dem Umhang
- [ ] Hüte bewegen sich (Krone funkelt, Visier scannt, Bandana flattert)
- [ ] Partikel kreisen um dich, Kill-Effekt zeigt Ring und Spirale

> Kosmetik siehst nur **du** – andere Spieler sehen sie nicht.
> Der Umhang wird seit 3.3 vom Bambus Client selbst gezeichnet (wehend) – mit Elytra wird er ausgeblendet.
